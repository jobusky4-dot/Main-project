Flight Ticket Price Analysis – Final Project

Project Overview

This project analyzes flight ticket prices using Python (Pandas, Seaborn, Matplotlib) and Power BI.
It identifies key factors affecting price such as airline, class, stops, duration, days left, and routes.

Contents

Cleaned dataset
Python notebook (EDA + visualizations)
Power BI dashboard
Final Stage‑4 documentation

Key Insights

Business class & premium airlines cost more
Non‑stop flights have higher prices
Last‑minute booking increases price
Longer duration → higher cost
Some routes are consistently expensive

Tools Used

Python (Pandas, NumPy, Seaborn, Matplotlib)
Power BI
GitHub for version control

Dashboard

Power BI dashboard shows all charts:
Airline vs Price, Class vs Price, Stops, Duration, Days Left, Route Heatmap.

 Conclusion
 
Clear patterns show how timing, class, airline, and route influence flight prices.
Useful for business decisions and customer planning.
